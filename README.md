# Tienda Don Pedro

Tienda de barrio ubicada en Itagüí. Don Pedro quiere llevar el control de sus productos y clientes frecuentes mediante un programa desarrollado en Python.

## 📁 Estructura del proyecto

- `productos.txt`: contiene los productos y sus precios.
- `clientes.txt`: contiene la información de los clientes frecuentes.
- `src/main.py`: archivo principal del programa.

## 🛒 Productos

| Producto | Precio |
|---|---:|
| Leche 1L | $4.200 |
| Pan tajado | $6.500 |
| Huevos x12 | $14.000 |
| Café 500g | $18.000 |
| Panela | $3.500 |
| Arroz 1kg | $4.500 |

```text
tienda-don-pedro/
```

## ▶️ Cómo ejecutarlo

Desde la terminal, ejecuta el siguiente comando en la carpeta raíz del proyecto:

```bash
python src/main.py
```
